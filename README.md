# DSP48A1

## Overview
This project implements the Xilinx DSP48A1 primitive using Verilog HDL.

The design was simulated and verified using ModelSim/QuestaSim.

## Features
- Verilog RTL implementation
- Self-checking Testbench
- Simulation using ModelSim
- Timing constraints (.xdc)
- DO script for simulation

## Tools Used
- Verilog HDL
- ModelSim / QuestaSim
- Xilinx Vivado

## Project Structure
```
DSP48A1.v        -> RTL Design
DSP48A1_tb.v     -> Testbench
run.do           -> Simulation Script
DSP48A1.xdc      -> Constraints File
Project 1.pdf    -> Project Report
```
